#  Multilingual Health Assistant

A multilingual healthcare assistant built using Python and Streamlit.

## Features

* Supports English, Hindi, and Punjabi
* Provides advice for common symptoms
* User-friendly Streamlit interface
* Covers:

  * Fever
  * Headache
  * Cough
  * Cold
  * Stomach pain
  * Sore throat

## Tech Stack

* Python
* Streamlit

## How to Run

```bash
pip install streamlit
streamlit run app.py
```
